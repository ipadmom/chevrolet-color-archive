# 2025-2026 current Order Guide specialty tranche

## Result

Twenty retained GM Electronic Order Guide sources were visually reviewed page
by page. The tranche publishes 30 exact configuration-color rows:

- 12 year-specific rows for the six-color combined Tahoe Police Package and
  Special Service table.
- 18 Woodland Green rows across Tahoe retail/fleet, Suburban, three Express
  configurations, and four Silverado HD or medium-duty configurations.

Every row is limited to the source heading, model year, color label, printed
SEO code, printed WA touch-up number, printed availability columns, and page
notes. No row establishes Forest Service Green. Isuzu Woodland Green `46U`
remains a separate Low Cab Forward identity with no printed WA number.

## Tahoe combined program

Both page 29 tables print the same six rows:

| Source label | SEO code | WA touch-up number |
|---|---|---|
| Victory Red | `5T4` | `WA-9260` |
| MSP Blue | `9V2` | `WA-5665` |
| Woodland Green | `9V5` | `WA-9015` |
| Dark Blue Metallic | `9V7` | `WA-722J` |
| Wheatland Yellow | `9W3` | `WA-253A` |
| Silver Ice Metallic | `9W5` | `WA-636R` |

The heading is “Police Package and Special Service.” The pages do not assign
individual rows separately to 9C1, 9C3, or 5W4. The archive therefore publishes
one combined program per year and does not duplicate the rows into inferred
PPV-only or SSV-only programs.
